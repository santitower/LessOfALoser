# Core AI model resources

This directory intentionally excludes model binaries from Git.

For the experimental `LessOfALoser-CoreAI` scheme, install one exported Core AI language-model resource folder here. Its top level must contain:

```text
metadata.json
*.aimodel/
tokenizer/
```

The recommended first model is the iOS export of `Qwen/Qwen2.5-1.5B-Instruct`. See `docs/CORE_AI.md` for export and installation instructions.
